# Country Conquest (Захват Стран)

Привет! Это мой авторский проект — браузерная геополитическая пошаговая стратегия, созданная на **React 19** и **Vite**. 

В этой игре я объединил механику случайного старта, тактическую экспансию по реальной векторной карте мира и азартные сражения с броском кубиков d5.

---

## О проекте и идея

Я хотел сделать динамичную, визуально строгую и захватывающую стратегию без лишней рутины: без скучного ожидания золота за клик, без загромождения экрана десятками ненужных кнопок и без детских эмодзи. 

Вместо этого я реализовал концепт **военного командного центра (War Room)**:
* Чистый, минималистичный интерфейс в темных тонах.
* Интерактивная векторная карта на 256 государств мира с реальной топологией и границами (включая морские пути для островных государств).
* Территории, окрашивающиеся государственным флагом моей империи по мере завоеваний.
* Профессиональная моноширинная телеметрия на шрифтах **JetBrains Mono** и **Inter**.

## Игровые механики, которые я разработал

### 1. Стартовая рулетка государств
При начале игры я запускаю анимированный барабан в стиле рулетки с флагами всех стран мира. Колесо замедляется со звуком треска колышков и случайным образом определяет державу, командование над которой я принимаю. Каждая страна имеет реальные базовые характеристики и уникальную национальную особенность (перк).

### 2. Выбор цели атаки (Случайный сосед)
Каждый раунд игра автоматически определяет одно из соседних государств, непосредственно граничащих с моей империей. Цель подсвечивается пульсирующим алым контуром. У меня есть выбор:
* **В бой!** — начать штурм и бросить кубики d5.
* **Другой сосед** — перенаправить разведку на другого соседа.

### 3. Боевая система и кубики d5 с множителем 1.1x
Я разработал формулу расчета базовой мощи, объединяющую три ключевых параметра:
$$\text{Базовая мощь} = (\text{Армия} \times k_{\text{армия}}) + (\text{ВВП} \times 150 \times k_{\text{ввп}}) + \left(\frac{\text{Население}}{1000} \times 25\right)$$

В бою обе стороны бросают пятигранный кубик **d5** (значения от 1 до 5), результат которого умножается на **1.1x**:
$$\text{Итоговая сила} = \text{Базовая мощь} \times (d5 \times 1.1)$$

У кого итоговое значение больше — тот побеждает.

### 4. Прогрессия мощи («Поглощение побежденных»)
Вместо системы золота я сделал честную механику поглощения ресурсов побежденных:
* При аннексии страны **+35% ее армии** вливается в мои вооруженные силы.
* **+40% ВВП и населения** присоединяются к моей экономической базе.
* Земли побежденного государства окрашиваются флагом моей империи.

### 5. Условия победы и поражения
* **Поражение (Истощение армии)**: при неудачной атаке моя армия несет потери в 40% личного состава. Если численность армии падает ниже 1 000 бойцов — наступает крах империи, игра показывает экран поражения со статистикой захватов и предложением перезапустить рулетку.
* **Победа (Мировое господство)**: цель кампании — подчинить себе все 256 государств планеты.

### 6. Оптимизация и звук
* **Мгновенная загрузка**: я оптимизировал карту, избавившись от сотен одновременных тяжелых сетевых запросов. Карта загружается за миллисекунды и обеспечивает стабильные 60 FPS при панорамировании и масштабировании.
* **Собственный Web Audio API**: все звуки (треск рулетки, грохот кубиков, боевой горн, фанфары победы) генерируются процедурно через синтезаторы частот в браузере — никаких внешних тяжелых mp3 файлов.

## Стек технологий

* **Frontend**: React 19, Vite 8
* **Картография**: SVG Vector Map Dataset (256 стран с полигонами и координатами границ)
* **Аудио**: Web Audio API (чистый процедурный синтез звуков)
* **Типографика**: JetBrains Mono + Inter

## Как запустить мой проект локально

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/El1teX/country-conquest.git
   cd country-conquest
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Запустите локальный сервер разработки:
   ```bash
   npm run dev
   ```

4. Откройте в браузере: `http://localhost:5173`
